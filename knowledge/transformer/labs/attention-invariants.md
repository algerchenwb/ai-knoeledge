# 注意力验证实验：改动输入后，哪些结果应该保持不变？

先阅读 [注意力与掩码](../02-attention-and-masks.md)。本实验不重新建立概念课程，而是用可运行的小矩阵补充四种可检验的关系。只依赖 Python 标准库，无需模型、GPU 或 API Key。

```bash
python knowledge/transformer/examples/attention_invariants.py
```

## 1. 从 Q/K/V 得到可以核对的数值

设 q=[1,0]，三个 K 分别为 [1,0]、[0,1]、[1,1]，三个 V 分别为 [10,0]、[0,20]、[10,10]。向量维度 dk=2，计算步骤如下。

| 步骤 | 结果 |
| --- | --- |
| q 与每个 K 点积 | [1,0,1] |
| 除以 √dk | 约 [0.707107,0,0.707107] |
| 在键轴做 softmax | [0.401112093,0.197775815,0.401112093] |
| 加权汇总 V | [8.022241854,7.966637220] |

脚本不是只检查权重和为 1，还与单独写出的标量公式比较：设 e=exp(1/√2)，权重应为 [e/(2e+1),1/(2e+1),e/(2e+1)]。这能发现缩放维度用错、softmax 轴用错和汇总顺序用错等问题。

当前只有一个查询，输出形状 [1,2]。一般情况下 Q=[nq,dk]、K=[nk,dk]、V=[nk,dv]，输出为 [nq,dv]。查询数可以和键值对数不同，Q/K 的特征维度必须相同，K/V 的位置数必须相同。

## 2. 被屏蔽的 Value 变化不应影响输出

禁止第三个键位置后，前两项重新归一化，权重约为 [0.669761549,0.330238451,0]，输出为 [6.697615493,6.604769013]。脚本把第三个 V 改成 [999999,-999999]，结果依然不变。

这里验证的是固定 Q/K 与 mask 下的这一层 attention。如果被修改的信息还可以沿其他未屏蔽路径传播，不能用这个局部实验宣称整个模型完全不受影响。禁止位置的分数不能仅仅设为 0：exp(0)=1，仍会占用权重。

## 3. 未来 token 变化不应改变更早的因果输出

设 X 的三行是 [1,0]、[0,1]、[1,1]，为简化计算令 Q=K=V=X。这只是数学实验；真实 self-attention 通常有不同的可学习投影。

| 查询行 | 允许的键位置 |
| --- | --- |
| 0 | 0 |
| 1 | 0、1 |
| 2 | 0、1、2 |

脚本将最后一行改为 [9,-4]，同时重算 Q/K/V。前两行输出保持不变，最后一行输出变化。这个实验比“注意力权重的上三角为零”更直接：它检查一个输入干预是否真的被隔离。

对训练调试，这是一种有用的检查思想：固定其他条件，只改未来输入，比较更早的输出。实际模型比较时要关闭 dropout 等随机因素，并选择合理浮点容差。完整多层模型的因果性仍需另外验证，本脚本只检查单层数学关系。

## 4. 无位置编码时，重排输入会相应重排输出

移除 causal mask，也不加入任何位置相关信息。把 X 的行按 [2,0,1] 重排，对应的 Q/K/V 一起重排，再计算 attention。新的输出行等于原输出按同样顺序重排的结果。

这叫置换等变，不叫整个矩阵数值不变。每个 token 对应的输出跟着它移动，模型没有从这种运算本身获得绝对顺序。

因此“甲收购乙”和“乙收购甲”的关系差异，需要位置信息或其他顺序结构参与表达。添加 causal mask 后，允许访问的集合与位置绑定，上述无掩码关系不能直接照搬。

脚本还实现经典正弦位置编码：维度为 4 时，位置 0 是 [0,1,0,1]，位置 1 的向量不同。这里只验证编码数值，不证明任意长度的模型泛化能力。

## 数值边界检查

softmax([1000,1001]) 应与 softmax([0,1]) 相同。实现先减去最大值再指数运算，避免直接 exp(1001) 溢出。

全屏蔽行没有合法的归一化分布，本例选择明确抛出 ValueError。不同框架或优化内核可能约定其他行为，集成时要检查具体 API。脚本的 bool mask 中 True 表示允许；不要假定所有框架都相同。

练习：把因果 mask 改成全允许，未来输入干预后哪个断言会失败？答：前两行输出保持不变的断言会失败。把禁止分数改成 0 呢？答：第三个 V 的巨大变化会污染输出，屏蔽隔离检查会失败。
