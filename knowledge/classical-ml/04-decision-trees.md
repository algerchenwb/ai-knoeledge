# 04｜决策树：模型怎样从数据里学出判断规则？

> 先修：特征、标签与 [独立评估](../ml-evaluation/README.md)。目标：理解节点分裂、叶子预测、纯度和复杂度控制。

## 1. 决策树像一串有条件的判断

假设判断某个地点是否属于高客流类别。一棵树可能先问“上月客流是否超过 1000”，再问“面积是否超过 500”。样本沿着条件进入分支，最后到达叶子，获得类别或数值预测。

这些阈值通常从训练数据中搜索，不是工程师手写。树也不知道“面积”的物理意义，只按照特征数值与标签关系挑选规则。业务场景中的数值均为虚构。

树是监督学习模型：没有对应标签，就不能直接用同样流程训练一个预测标签的决策树。

## 2. 分类树怎样选择分裂？

分类节点可以用 Gini 不纯度表示混杂程度：

Gini=1−Σpₖ²，其中 pₖ 是该节点各类别占比。

两类各占一半时 Gini=0.5；全是同一类时 Gini=0。分裂时比较“父节点不纯度”与“子节点按样本量加权的不纯度”，希望降低混杂。

四条数据 x=[1,2,3,4]，标签 y=[0,0,1,1]。在 2.5 处分裂，两边各只有一类，子节点 Gini 都是零，总改善为 0.5。

若在 1.5 分裂，左边一个负类，右边三个样本中两正一负。右边 Gini=4/9，加权后为 3/4×4/9=1/3，改善仅为 1/6。因此此例 2.5 更好。

真实训练需要比较多个特征与多个候选阈值。贪心算法在当前节点选较好的分裂，不保证整棵树是所有可能树中的全局最优。

## 3. 回归树与分类树的区别

回归树预测数值，常见平方误差准则下，叶子输出该叶中训练标签的平均值。分裂目标是让叶内数值更接近。

例如左叶标签 [10,12]，输出 11；右叶标签 [30,34]，输出 32。预测是分段常数，不是相邻点之间画平滑曲线。

不同损失准则可能对应不同叶子统计，例如绝对误差准则常与中位数有关。不要把“永远取平均”当成所有树实现的通用定义。

## 4. 树的概率从哪里来？

无样本权重的常见分类树，某叶有 8 个正类、2 个负类，正类概率估计为 0.8。它来自叶内训练分布，并不意味着真正发生率已经证明是 80%。

若叶内只有一个正类样本，预测概率可能为 1，但证据非常薄弱。使用样本/类别权重时，应按有效权重理解叶子比例。概率还需在独立数据上检查校准。

## 5. 控制过拟合的几种方式

| 参数或方法 | 作用 | 常见误区 |
| --- | --- | --- |
| max_depth | 限制从根到叶的深度 | 深度更大不保证验证更好 |
| min_samples_leaf | 要求叶子有足够样本 | 小叶子可能只记住噪声 |
| min_samples_split | 限制何时继续分裂 | 与叶子最小样本量不是同一约束 |
| max_leaf_nodes | 限制叶子数量 | 与固定深度不是等价规则 |
| ccp_alpha | 成本复杂度剪枝 | alpha 越大通常更强剪枝，需验证选择 |

预剪枝是在生长时限制结构；后剪枝是在候选树结构上折中拟合与复杂度。两者都是控制模型复杂度，不等于清理错误数据。

## 6. 可运行的最小例子

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier, DecisionTreeRegressor

X = np.array([[1.], [2.], [3.], [4.]])
y = np.array([0, 0, 1, 1])
clf = DecisionTreeClassifier(max_depth=1, random_state=42).fit(X, y)
print("split", clf.tree_.threshold[0])
print("class", clf.predict([[1.5], [3.5]]))
assert np.isclose(clf.tree_.threshold[0], 2.5)
assert np.array_equal(clf.predict([[1.5], [3.5]]), [0, 1])

reg = DecisionTreeRegressor(max_depth=1, random_state=42).fit(
    X, [10., 12., 30., 34.]
)
print("regression", reg.predict([[1.5], [3.5], [100.]]))
assert np.allclose(reg.predict([[1.5], [3.5], [100.]]), [11., 32., 32.])
```

x=100 仍进入右叶，得到 32；这说明普通常数叶回归树不自然延长趋势。训练数据最大值之外有新趋势时，不能靠树名推断它会合理外推。

## 7. 为什么树通常不要求标准化？

连续特征的严格单调变换通常保留样本顺序，也保留可用分割的样本划分，因此树不像带系数惩罚的线性模型那样敏感于单位尺度。

这不是“所有预处理都可以省略”。缺失、类别编码、泄漏和口径变化仍需处理；浮点精度、近似分桶及新样本映射也可能产生差异。这里描述的是分裂机制，不承诺任何变换下实现结果完全相同。

scikit-learn 的普通树不能仅因为数据是数字就理解类别 ID 的业务语义。给业态编号 1、2、3，会引入按数值阈值分组的约束，需考虑合理编码。原生类别支持取决于具体算法与版本。

## 8. 单棵树为何不稳定？

两个候选分裂效果差不多时，少量数据变化就可能换掉根节点，进而改变很多后续分支。单棵深树容易高方差，随机森林通过组合不同树缓解这一点。

“规则能读懂”不代表规则一定正确，也不代表规则是因果关系。模型可能把泄漏字段放在根节点，产生极清晰但无效的解释。

## 9. 练习与答案

1. 一个叶只有两条样本且全为正类，概率 1 是否表示确定？  
   答：不表示，样本证据少，也可能过拟合或未校准。

2. max_depth=1 是否只能用一个特征？  
   答：最终树只有根分裂，实际会在候选特征中搜索；训练时并非只查看一个输入。

3. 树预测客流超出训练范围，是否会继续增长？  
   答：普通常数叶树不会自动延长趋势，它按路径返回叶值。

4. 训练准确率 100% 应如何处理？  
   答：看独立验证、叶子大小、深度和泄漏，不应仅据此宣布成功。
