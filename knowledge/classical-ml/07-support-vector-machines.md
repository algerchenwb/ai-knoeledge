# 07｜支持向量机：间隔、支持向量与软约束

> 目标：理解 SVM 怎样选择分类边界，区分分类分数和概率，并读懂 C 的作用。

## 1. 分得开还不够，边界应该放在哪里？

假设一维数据负类在 −2、−1，正类在 1、2。任何位于 −1 与 1 之间的阈值都能分对训练样本，但靠近某一类的边界，面对小扰动可能更脆弱。

硬间隔线性 SVM 在可分情况下，寻找使最近样本离边界尽可能远的分隔超平面。这个“留出较宽缓冲区”的直觉叫最大间隔。

它不是保证所有未来样本都能分对的定理。泛化仍取决于数据、特征与独立验证。

## 2. 分数、功能间隔与几何间隔

线性分数 f(x)=w·x+b，边界为 f(x)=0。推导常把标签写成 y∈{−1,+1}，y×f(x) 为功能间隔。

几何上，点到超平面的距离是 |f(x)|/||w||。把 w 和 b 同时乘以十，不改变边界，也不改变几何距离，却会把分数放大十倍。因此分数本身不能直接当作距离，更不能直接当成概率。

用规范约束 yᵢf(xᵢ)≥1 时，两条支持超平面之间的总宽度是 2/||w||。最大化这个宽度等价于缩小 ||w||，同时满足正确侧的约束。

## 3. 支持向量是什么？

在前面的例子中，离边界最近的 −1 与 1 决定间隔，−2 与 2 没有额外收紧边界。它们是典型支持向量。

更一般地，支持向量是决策函数中具有非零对偶系数的训练样本。软间隔模型中，边界附近、间隔内甚至分错的点都可能成为支持向量。不要把它简化成“所有支持向量都刚好分类正确且在边线上”。

支持向量是训练样本，不是模型自己生成的新向量。核方法的预测可以只汇总支持向量贡献，但支持向量很多时，推理也会变重。

## 4. 不可分数据与 hinge loss

现实标签可能重叠或有噪声，不适合要求每条训练记录严格分开。软间隔允许违反间隔，典型目标为：

0.5||w||² + C×Σ max(0,1−yᵢf(xᵢ))。

后面是 hinge loss：
- y×f≥1，损失为 0。
- y×f=0.5，类别虽正确，但间隔不足，损失为 0.5。
- y×f=−0.5，分错，损失为 1.5。

它不只惩罚分错，也惩罚离边界太近的正确样本。LinearSVC 常见默认使用 squared_hinge，不能将所有 SVM 实现都当成完全相同目标。

## 5. C 大小如何理解？

C 越大，违反间隔的代价相对更重；C 越小，通常更愿意牺牲部分训练拟合来限制参数幅度。

它的方向与 Ridge 的 alpha 不同。C 大不代表更高质量，也不意味着一定能正确分开所有数据。标签重叠或噪声存在时，过度追求训练正确可能降低验证表现。

C 的数值还与特征尺度、样本数量、权重和损失约定有关。不能不看目标函数就与其他模型的正则化数字直接比较。

## 6. 可运行的一维间隔核对

```python
import numpy as np
from sklearn.svm import SVC

X = np.array([[-2.], [-1.], [1.], [2.]])
y = np.array([-1, -1, 1, 1])
model = SVC(kernel="linear", C=10).fit(X, y)
print("coef", model.coef_, "intercept", model.intercept_)
print("support", model.support_vectors_.ravel())
print("score", model.decision_function([[-0.5], [0.5]]))
assert np.allclose(model.coef_, [[1.]])
assert np.allclose(model.intercept_, [0.])
assert np.allclose(np.sort(model.support_vectors_.ravel()), [-1., 1.])
assert np.array_equal(model.predict([[-0.5], [0.5]]), [-1, 1])
print("total margin width", 2 / np.linalg.norm(model.coef_))
```

此例得到宽度约 2，是模型机制核对，不是泛化评估。实际输入不一定是一维，类别标签也可以是字符串；预测分数的符号应结合 classes_ 与具体实现解释。

## 7. SVC(kernel="linear") 与 LinearSVC 有什么区别？

它们都能学习线性分类器，但使用不同求解实现、目标选项、截距正则化和多分类策略，因此预测不必完全一致。

LinearSVC 通常更适合较大线性问题，但没有 SVC 的所有属性，例如常规 support_vectors_。选择哪个应看规模、稀疏性、指标和训练时间，不能只把一个当成另一个的“更快同款”。

SVC 多分类内部通常训练一对一分类器；decision_function_shape="ovr" 改的是对外分数形式，不等于内部改成一对其余训练。四类的一对一组合数为 4×3/2=6。

## 8. decision_function 不是 predict_proba

SVM 原始分数可用于排序与选阈值，但不自动形成 [0,1] 的概率。SVC(probability=True) 会增加额外概率估计过程与训练开销，概率预测和硬分类还可能存在不一致。

工程补充：如果有严格分组或时间验证要求，要检查概率校准的数据划分是否符合协议。普通内部切分不自动隔离同一 POI 或预测未来时点。

也不能把任意 SVM 分数直接套 sigmoid，就宣称得到校准概率；概率校准应在合适数据上学习并独立评估。

## 9. 特征尺度与业务输入

距离和间隔依赖输入几何。面积、人次与比例的尺度不同，可能让某列支配模型。通常使用训练集拟合的 StandardScaler，并放进交叉验证 Pipeline。

类别 ID 作为数值会引入顺序和距离假设，需合理编码。字段来自未来、单位变化和标签错误也不会因为使用 SVM 自动消失。

## 10. SVR：支持向量回归

SVR 用类似约束思想预测连续值。epsilon-insensitive loss 是 max(0,|y−预测|−epsilon)，在 epsilon 范围内的误差不额外计入这项损失。

epsilon 描述目标数值单位中的容忍带，不是百分比准确率。例如客流单位是“人”，epsilon=10 通常表示十人的绝对误差尺度；换成“千人”单位，含义随之改变。

SVR 与 SVC 面向不同目标，不能对连续客流随意编码成类别后说问题没有变化。核 SVR 同样要考虑尺度、训练规模和外推。

## 11. 练习与答案

1. 分数 3 是否表示正类概率 300%？  
   答：不是，原始决策分数不是概率。

2. 分类正确但 y×f=0.5，hinge loss 是多少？  
   答：0.5，正确类别也可能违反间隔要求。

3. C 增大是否等于更强正则化？  
   答：通常相反，它加重间隔违反惩罚。

4. support_vectors_ 很多意味着预测免费吗？  
   答：不是，核预测要计算许多支持向量贡献。
