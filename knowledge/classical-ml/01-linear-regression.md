# 01｜线性回归：从特征到数值预测

> 目标：理解系数、截距、残差与最小二乘，能建立一个可核验的数值预测基线。

## 1. 模型不是凭空猜数字

假设要预测某个地点下月客流，用历史客流、面积和周边商户数作为输入。线性模型可以写成：

ŷ=b+w₁x₁+w₂x₂+w₃x₃。

x 是已知特征，w 是模型从训练数据学习的系数，b 是截距，ŷ 是预测。公式中没有“下月实际客流”作为输入，否则可能泄漏。

若一个示意模型是 ŷ=100+0.8×上月客流，输入 1000，预测为 900。这里的 0.8 是人为举例，不表示真实业务规律。

模型学习的是训练数据中的统计关系。是否能够预测未来，仍要用 [独立验证与时间切分](../ml-evaluation/02-validation-and-cross-validation.md) 检查。

## 2. 系数和截距怎样读？

在其他输入保持不变时，x₁ 增加一单位，预测增加 w₁。这是一种模型内部解释；若现实中无法只改变一个输入而保持其余条件不变，就不能直接把它当成真实世界的因果效应。

截距是输入都为零时的预测。所有输入为零可能不在实际数据范围内，截距仍用于定位模型，不一定有直接业务含义。

系数大小还取决于单位。面积由平方米换成千平方米，同一关系的系数会放大一千倍。不能不看尺度就说“大系数特征更重要”。

## 3. 残差与最小二乘

定义残差 e=y−ŷ，即真实值减预测值。正残差表示低估，负残差表示高估。本篇统一这个定义；其他代码可能用相反符号，平方损失不受符号影响。

普通最小二乘寻找让残差平方和最小的系数：

RSS=Σ(yᵢ−ŷᵢ)²。

为什么平方？它让大误差受到更重惩罚，也提供便于优化的数学结构。但如果标签有极端异常值，平方会让异常点影响很大。选择平方损失不是业务永远正确的答案。

训练使用平方和或均方误差，在固定样本集和没有其他项时，会得到同样的最优系数。添加正则化或不同权重后，要核对归一化约定。

## 4. 手算一条直线

取 x=[1,2,3]，y=[2,3,5]。均值 x̄=2，ȳ=10/3。

一元回归的斜率为：
w=Σ(xᵢ−x̄)(yᵢ−ȳ)/Σ(xᵢ−x̄)²=3/2。

截距 b=ȳ−w×x̄=1/3。三个预测约为 [1.8333,3.3333,4.8333]，残差为 [1/6,−1/3,1/6]。

残差平方和为 1/6，均方误差为 1/18。新输入 x=4 的预测为 19/3≈6.3333；由于它在训练范围之外，这属于外推，不代表现实结果一定如此。

## 5. 可运行的 scikit-learn 示例

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

X = np.array([[1.], [2.], [3.]])
y = np.array([2., 3., 5.])
model = LinearRegression().fit(X, y)
pred = model.predict(X)
print("coef", model.coef_, "intercept", model.intercept_)
print("train MSE", mean_squared_error(y, pred))
print("x=4", model.predict([[4.]]))
assert np.allclose(model.coef_, [1.5])
assert np.isclose(model.intercept_, 1/3)
assert np.isclose(mean_squared_error(y, pred), 1/18)
```

这是手算核对，不是泛化评估。三个训练点上的误差不能当作模型上线效果；真实应用需单独留出数据。

普通 LinearRegression 也不意味着内部一定使用前面深度学习章节的逐批梯度下降。库会根据数据与选项使用适当数值求解方法，不应从模型名称推断训练实现。

## 6. 多重共线性为什么让系数不稳定？

设两个输入列几乎相同：总到访次数和总到访次数的单位换算。模型可通过多种系数组合产生接近相同的预测。

如果 x₂=x₁，公式 w₁x₁+w₂x₂=(w₁+w₂)x₁，数据只能约束系数之和，不能唯一识别各自贡献。小量噪声就可能让估计的单个系数大幅变化。

重要区别：预测比较稳定，不代表单个系数可靠；单个系数不稳定，也不证明模型完全无法预测。可以移除冗余特征、增加有效数据，或使用 Ridge 等正则化，但这些措施不能自动建立因果解释。

不要把共线性概括成“所有特征必须统计独立，否则不能回归”。关键问题是设计矩阵的秩、近线性依赖及其带来的估计稳定性。

## 7. 线性模型能处理非线性关系吗？

“线性”通常指对系数线性，不一定只能对原始 x 画直线。例如输入变换为 x 与 x²：

ŷ=b+w₁x+w₂x²。

它对 x 是曲线，对 w 仍是线性模型。交互项 x₁x₂ 也能表达两个输入联合作用。增加这类特征会提高表达能力，同时可能放大过拟合和外推风险。

这不是让模型无限加高次项的理由。候选变换应在训练/验证流程内选择，任何需要学习统计参数的预处理也只能从训练数据学习。

## 8. 客流预测的额外边界

以下为工程扩展：

- 客流不可为负，但普通线性回归可能预测负数。截断为零是一个决策规则，需重新评估误差，不能偷偷修改输出却沿用旧分数。
- 小店和大商场的规模差异会影响总体 MSE。应报告 MAE、规模分层误差以及可上线基线。
- 节假日、活动和季节变化可能使简单线性关系失效，应检查未来时间窗口的验证表现。
- 输入字段的统计口径、单位和可用时间要一致，不能仅凭同名字段就认为兼容。

## 9. 练习与答案

1. 系数 0.8 是否证明“增加历史客流会造成未来客流增长”？  
   答：不证明，只是模型中的条件关联。

2. 两列完全相同，系数各是多少是否唯一？  
   答：通常不唯一，预测可以由不同系数组合给出。

3. 加入 x² 后是否就不是线性模型？  
   答：仍可对系数线性，但输入到输出关系可以是曲线。

4. 训练误差很小，是否应直接上线？  
   答：不应，还要验证新数据、对比基线、检查业务约束。
