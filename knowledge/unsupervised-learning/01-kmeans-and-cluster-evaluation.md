# 01｜K-means：没有标签时怎样把相近数据分组？

> 目标：理解聚类目标、中心更新、特征尺度、K 的选择与评估边界。

## 1. 聚类与分类有什么不同？

分类有事先定义的标签，例如“正常/异常”，模型学习预测这些标签。聚类通常没有这样的训练标签，只根据给定表示与距离寻找相近样本。

例如给 POI 提供历史客流、面积和到访频次，聚类可能形成不同特征组合的组。算法不会自动告诉你哪个是“高价值门店”。组的业务解释需要另行检查，不能把无监督结果包装成已验证的分类。

簇编号 0、1、2 是标识，不是排序。换一次初始化或样本顺序，编号可能改变，而分组关系基本一样。比较两次结果应比较成员关系，不应只看编号是否相同。

## 2. K-means 优化什么？

指定 K 个中心，将样本分给最近中心，尽量降低到所属中心的平方欧氏距离之和：

inertia=Σᵢ minⱼ ||xᵢ−μⱼ||²。

中心 μ 是簇内样本的均值，通常不等于某条实际记录。因此“选出 K 个中心”不意味着“选出 K 个代表门店”。需要实际代表对象时，可以找最近记录，或研究其他聚类方法。

K 是需要预先选择的超参数。算法不会天然发现唯一正确的业务分组数。

## 3. 用四个数手算

数据 x=[1,2,8,9]，K=2，初始中心为 1 和 9。

先分组：1、2 更靠近 1，8、9 更靠近 9。更新中心为 1.5 和 8.5。再次分组不变，得到稳定结果。

平方距离和是 4×0.5²=1。这是此例的 inertia；它不是准确率，也不是一个跨数据集直接比较的标准化分数。

算法一般交替执行“最近中心分配”和“均值更新”。它依赖初始化，可能停在局部较优结果。k-means++ 与多次初始化有助于改善搜索，不保证找到全局最优。

## 4. 特征尺度决定什么是“近”

假设面积在 10—1000，比例指标在 0—1，直接算欧氏距离可能主要由面积决定。若这是明确业务偏好，可以接受；若不是，需要考虑标准化或合理权重。

StandardScaler 把每列按训练均值与标准差转换，但不是自动找到最佳业务距离。若一列噪声大，标准化可能让它与有用列同样重要。类别 ID 也不能因为写成数字就当作连续距离。

将经纬度、金额、人数和比例混合进一个向量时，先说明每种距离差异的意义，再决定缩放。不能简单认为“所有列都有数，就能聚类”。

## 5. 为什么不能只挑 inertia 最小的 K？

增加 K 通常允许模型把数据分得更细，使最佳可达 inertia 不增。K 接近样本数时，可能把每条样本当一个簇，距离接近零，却毫无概括意义。实际不同初始化得到的局部结果可能出现波动。

常用办法包括：
- 肘部法：找继续增加 K 后收益明显变小的位置，但不一定存在清晰拐点。
- 轮廓系数：同时考虑簇内紧密和簇间分离。
- 稳定性：改变随机种子或样本后，成员结构是否仍接近。
- 业务审核：组是否有明确用途、足够样本和可解释差异。

它们回答不同问题，没有一个分数能自动确定“真实业务类别”。

## 6. 轮廓系数的分母和边界

对一个样本，a 是它与同簇其他样本的平均距离；b 是它到其他各簇的平均距离中最小的一项。

s=(b−a)/max(a,b)。

接近 1，说明在当前距离下与本簇较近、其他簇较远；接近 0，表示边界不清；负值表示它可能更靠近别的簇。总体分数是样本分数平均。

计算要求有效标签数至少 2，且少于样本数。单簇或每样本一个簇不能据此正常评估。单成员簇也有实现约定，不能把它当成完美分组。

轮廓系数偏好紧密分离的几何结构，不等于业务价值，也不一定适合比较任意形状的密度簇。

## 7. 可运行的手算核对

```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

X = np.array([[1.], [2.], [8.], [9.]])
model = KMeans(n_clusters=2, n_init=10, random_state=42).fit(X)
print("centers", np.sort(model.cluster_centers_.ravel()))
print("inertia", model.inertia_)
print("silhouette", silhouette_score(X, model.labels_))
assert np.allclose(np.sort(model.cluster_centers_.ravel()), [1.5, 8.5])
assert np.isclose(model.inertia_, 1.)
assert model.labels_[0] == model.labels_[1]
assert model.labels_[2] == model.labels_[3]
assert model.labels_[0] != model.labels_[2]
print("new samples", model.predict([[1.8], [8.2]]))
```

predict 把新样本分给已有最近中心，不会自动增加一个簇，也不会自动判断它是不是离所有中心都很远的异常点。若要拒绝分配，需要另外定义距离规则并验证。

## 8. 形状与数据规模

K-means 更适合在所选表示中相对紧凑、尺度相近的簇。弯月形、细长形或密度差异很大的数据可能不适合；不能只靠加大 K 修复所有形状问题。

MiniBatchKMeans 使用小批量近似更新，可能降低大数据计算成本，结果不必与完整 K-means 完全一致。选择时同时记录稳定性、分数和资源消耗。

## 9. 在预测流程中怎样避免泄漏？

若聚类只是描述当前全量对象，全量拟合可能符合分析目的；应明确它是当前样本描述。

若用簇编号或到中心的距离作为下游监督模型特征，聚类也属于预处理，应该在训练集拟合，再转换验证和测试数据。交叉验证时每折重新学习，不能先用所有数据得到中心，再宣称下游评估独立。

## 10. 练习与答案

1. 第 2 簇是否一定比第 1 簇价值更高？  
   答：不是，编号本身没有业务等级。

2. K=样本数，inertia=0 能说明分组最有用吗？  
   答：不能，只表示可以记住每条记录。

3. 聚类中心是否必须是一条真实记录？  
   答：不是，它通常是均值。

4. 新点远离所有中心，predict 会返回异常吗？  
   答：普通 K-means 仍分给最近中心，异常判断需另设规则。
