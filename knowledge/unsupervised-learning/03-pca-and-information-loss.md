# 03｜PCA：把多个特征压缩成少量变化方向

> 目标：理解主成分、方差解释率、重建与信息损失，不把降维当作自动特征选择。

## 1. PCA 在做什么？

PCA 寻找数据变化最大的方向，把多个输入特征投影到较少的坐标轴上。它是线性降维方法，通常不需要标签。

例如三个人群指标高度相关，数据可能主要沿某个共同方向变化。PCA 用一个或几个方向概括这些变化，但不会自动把方向命名为“消费能力”或“位置价值”。

主成分是原特征的线性组合，不是简单保留某几列。它与选择重要原始字段是不同操作。

## 2. 为什么先减均值？

PCA 分析的是相对均值的变化。常见流程是每列减去训练均值，再寻找变化方向。

scikit-learn PCA 默认中心化，不自动按每列标准差标准化。如果面积数值很大、比例数值很小，高方差方向可能主要反映面积单位。是否使用 StandardScaler 是业务与模型选择问题，不是 PCA 自动解决的事。

使用标准化，相当于改变所分析的几何关系。数据中的高波动特征可能是噪声，标准化也可能放大低变化噪声，因此需验证。

## 3. 方向、坐标与重建

设中心化样本为 x，第一主成分单位方向为 v。新的一维坐标 z=x·v。近似重建为 x̂=zv，再加回均值。

方向 v 与 −v 表示同一条轴。不同算法或版本可能翻转符号，同时 z 也翻转，重建结果不变。不能把符号变化误判成模型失效。

多个主成分通常互相正交，依次描述在剩余方向上的最大方差。这不表示它们具有独立业务因果含义，也不表示一般数据中主成分统计上必然独立。

## 4. 一个能完全重建的例子

X=[[−2,−2],[−1,−1],[1,1],[2,2]]。

点全在 y=x 的直线上，均值为零。第一主成分方向可取 [1/√2,1/√2]，一维坐标为 [−2√2,−√2,√2,2√2]。

两个原始维度其实只有一个变化方向，保留一维仍可完全重建。真实数据有噪声时，低维重建通常只能近似。

## 5. 可运行的投影核对

```python
import numpy as np
from sklearn.decomposition import PCA

X = np.array([[-2., -2.], [-1., -1.], [1., 1.], [2., 2.]])
pca = PCA(n_components=1, svd_solver="full").fit(X)
Z = pca.transform(X)
reconstructed = pca.inverse_transform(Z)
print("component", pca.components_)
print("variance ratio", pca.explained_variance_ratio_)
print("reconstruction error", np.mean((X - reconstructed)**2))
assert Z.shape == (4, 1)
assert np.allclose(pca.explained_variance_ratio_, [1.])
assert np.allclose(np.abs(pca.components_[0]), [1/np.sqrt(2)]*2)
assert np.allclose(reconstructed, X)
```

这里用绝对值检查方向，避免符号约定导致无意义失败。完整重建来自人工数据的共线性，不是“一维能保留任意二维数据”。

## 6. 方差解释率不是预测准确率

explained_variance_ratio_ 表示各主成分占原数据总方差的比例。前几个加起来达到 95%，表示保留了当前表示下 95% 的变化量。

它不表示：
- 保留了 95% 的真实业务知识。
- 分类准确率会达到 95%。
- 目标相关信息只损失 5%。
- 低方差方向不重要。

例如第一列有很大的随机波动，第二列波动很小却能区分标签。PCA 不看标签，可能保留第一列而丢掉第二列。下游监督模型是否受益，需要看独立验证指标。

## 7. PCA 与 Whitening

普通 PCA 得到各主成分坐标，方差大小不同。whiten=True 进一步缩放，使保留成分的训练方差按实现约定接近单位方差。

这会改变距离结构，可能帮助假设各方向尺度相近的后续模型，也可能放大较小方差方向的噪声。它不是“一定提高聚类”的按钮。

即便 whitening 后，每个方向的业务含义也不自动变清楚。保留了多少维、如何缩放和下游距离必须一起记录。

## 8. 无监督也需要保护评估边界

若 PCA 用于下游预测，不能先用训练加测试数据拟合主成分，再对下游模型进行所谓独立测试。主成分已利用测试数据的分布。

正确流程是：训练部分 fit scaler 和 PCA，再用已有变换处理验证/测试。交叉验证每折重学，通常通过 Pipeline 实现。

如果只是对当前数据做描述性可视化，全量 PCA 可能合理，但应明确它是当前数据的描述，不是未来预测泛化的证明。

## 9. PCA 图不等于完整的数据关系

两维投影可能让高维相距很远的点看起来靠近，也可能隐藏对分类关键的方向。投影图上的聚集不是自动确认“天然类别”。

工程扩展：压缩 Embedding 可以节省存储与检索计算，但原向量空间中的相似关系可能变化。应检查检索 Recall@K、排名质量与成本，而不是只看方差解释率。PCA 也不能把不同 Embedding 模型的空间自动对齐。

新数据必须使用同一均值、成分和缩放规则。重新 fit 后即使维度一样，新坐标含义也可能不同，需要版本管理。

## 10. 大数据与其他降维方法

IncrementalPCA 通过批次处理降低一次装载全量数据的压力，不保证与完整 PCA 的数值完全一致。批次和顺序仍要记录。

稀疏文本数据可以研究 TruncatedSVD，它与中心化 PCA 的流程不同。不能为做 PCA 把很大的稀疏词频矩阵无条件转成密集矩阵。

PCA 是线性投影，复杂非线性结构可能无法在少量主成分中表达。其他可视化降维方法也有自己的约束，不应仅凭图好看就宣布业务分群正确。

## 11. 练习与答案

1. PCA 保留 95% 方差，分类准确率一定至少 95% 吗？  
   答：不是，方差与标签预测是不同目标。

2. 主成分由正变负，需要立刻重新训练吗？  
   答：先检查是否整体符号翻转，等价方向不意味着信息变化。

3. PCA 是否自动标准化每列？  
   答：常见 scikit-learn PCA 中心化但不自动按标准差缩放。

4. 用测试数据 fit PCA，再测试分类器是否独立？  
   答：不独立，预处理已使用测试分布。
