# 02｜DBSCAN：按密度找簇，并保留未归组样本

> 目标：理解邻域、核心点、边界点与噪声，不把 eps 当作整个簇的直径。

## 1. 不必预设簇数，不等于没有参数

DBSCAN 将高密度区域看成簇，通过邻域连接扩展，稀疏区域可以不归组。它不要求事先输入 K，但需要选择距离函数、eps 与 min_samples。

K-means 希望点靠近中心；DBSCAN 关心局部邻域是否够密，因此可发现不规则形状。然而密度标准是全局设置，不同密度群体可能难以兼顾。

## 2. 三种点

在无样本权重的基本情形下：

| 类型 | 判断 | 结果 |
| --- | --- | --- |
| 核心点 | eps 邻域内样本数达到 min_samples | 可以继续扩展簇 |
| 边界点 | 自己不够密，但位于某核心点邻域 | 可归入簇，不独立继续连接扩展 |
| 噪声点 | 既非核心，也未归入核心点扩展出的簇 | 常标记为 −1 |

scikit-learn 的 min_samples 包含点自身。min_samples=3 意味着自身加上至少另外两个邻域样本；不要把它误读为必须有三个“其他点”。使用 sample_weight 时定义还涉及邻域总权重，应按 API 核对。

## 3. 手算一维例子

x=[0,0.1,0.2,3,3.1,3.2,10]，eps=0.15，min_samples=3。

0.1 的邻域包含 0、0.1、0.2，共三个，是核心点。0 和 0.2 的邻域只有两个，不是核心，但邻近核心点，因此是边界点。

3.1 同理成为第二簇核心，3 与 3.2 是边界点。10 附近只有自身，是噪声。结果为两个簇加一个噪声点，簇编号本身可换。

## 4. eps 不是簇直径

假设核心点 A 靠近 B，B 靠近 C，但 A 与 C 相距很远。邻域可以通过核心点链条连接，所以同一簇的最远两点距离可能远大于 eps。

一个桥接的高密度链也可能把原本期望分开的群体连成一个簇。检查结果不能只看“每条边不超过 eps”，还要看整簇的空间与业务含义。

边界点不能像核心点一样把两个簇任意连起来。某边界点邻近两个不同簇的核心时，归属可能受到数据遍历顺序影响。

## 5. 为什么参数容易失效？

- eps 太小：邻域不足，大量点标成噪声。
- eps 太大：不同簇可能合并。
- min_samples 过大：小群体可能无法形成核心。
- min_samples 太小：随机稀疏点也可能被连起来。
- 数据尺度变化：相同 eps 表示不同密度含义。
- 不同区域密度差很多：单一参数很难同时处理。

邻近距离图可帮助寻找候选 eps，但不是自动给出业务正确答案。应检查不同参数下的簇数量、覆盖率、核心比例和稳定性。

## 6. 经纬度不能直接把度当米

业务扩展：eps 的单位来自距离函数。若直接在经纬度度数上使用欧氏距离，eps=100 不表示 100 米；经度一度的物理距离还随纬度变化。

可以考虑合理投影后的米制坐标，或球面距离及弧度约定。具体实现需确认坐标系统与距离定义。GCJ-02、BD-09 与 WGS84 不能混合后直接算距离。

本篇完整例子是人工一维数值，不提供未经空间基准验证的地理聚类代码。实际地域统计还需要考虑采样密度、数据覆盖和业务边界，而不是把所有噪声点解释为无人区域。

## 7. 可运行的邻域核对

```python
import numpy as np
from sklearn.cluster import DBSCAN

X = np.array([[0.], [0.1], [0.2], [3.], [3.1], [3.2], [10.]])
model = DBSCAN(eps=0.15, min_samples=3).fit(X)
labels = model.labels_
print("labels", labels)
print("core indices", model.core_sample_indices_)
assert set(model.core_sample_indices_) == {1, 4}
assert labels[-1] == -1
assert labels[0] == labels[1] == labels[2]
assert labels[3] == labels[4] == labels[5]
assert labels[0] != labels[3]
assert len(set(labels) - {-1}) == 2
```

不要断言“第一簇必须编号 0 就代表某业务类别”。此例断言成员关系和噪声定义，保留编号可交换的性质。

## 8. 噪声不等于错误或风险

噪声点仅表示在当前表示、距离与参数下，不满足聚类归属条件。它可能是：
- 真实但少见的对象。
- 采样不足的群体。
- 数据错误或异常值。
- 被不合理尺度与参数排除的普通对象。

要把它用于异常检测，应增加明确标签、人工审核或其他验证。不能仅凭 −1 就触发业务处罚或删除记录。

## 9. 如何评价含噪声的结果？

轮廓系数等指标不天然理解 −1 是“多个未归组点”，可能把所有噪声当一个普通簇。这会扭曲比较。

若只对非噪声样本算分，应同时报告覆盖率。例如一个方案只保留 20% 最紧密点，分数很高，不能直接认为胜过覆盖 90% 的方案。单个剩余簇也不能正常计算轮廓系数。

还应看簇是否稳定、业务上是否可解释、每簇样本数是否足够。DBSCAN 可发现非凸簇，因此不能只用偏好紧密凸形结构的指标评判。

## 10. 新样本与内存限制

scikit-learn DBSCAN 不像 K-means 那样提供普通 predict，把新点自动归到冻结模型。可以另设“最近核心点”规则，但这不是重新运行 DBSCAN 的严格等价结果。

当前实现在邻域很大等情况下有 O(n²) 最坏内存风险。处理大量点时应先估算邻域密度，考虑稀疏邻域图、去重与权重等方案；不能不加检查地构建完整距离矩阵。

分块独立聚类也可能把跨块连接切断，需要单独处理边界；按城市切块属于业务约束，不是原算法全量结果的无损加速。

## 11. 练习与答案

1. min_samples=3 是否不算自身？  
   答：scikit-learn 的基本无权重约定包含自身。

2. 同一簇最远两点能超过 eps 吗？  
   答：能，核心点链可以连接很大范围。

3. 噪声比例高一定证明数据错误吗？  
   答：不一定，可能参数、尺度、覆盖或密度不合适。

4. 过滤噪声后分数变高，能忽略覆盖率吗？  
   答：不能，否则可能只留下容易聚类的少量样本。
