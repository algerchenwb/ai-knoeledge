# Isomap：沿着数据表面走，而不是直接抄近路

读前建议：[PCA](03-pca-and-information-loss.md)、[t-SNE](08-tsne-and-visualization-pitfalls.md)。本篇独立编写中文解释与实验，以 scikit-learn 官方开源仓库为依据。目标是理解距离如何被改变，以及这种改变什么时候可信。

## 1. 为什么直线距离有时会误导我们

把一条长纸带弯成 U 形，两端在桌面上很近，但沿纸带走仍然很远。原始二维坐标描述的是“摆在桌面哪里”，纸带上的位置则只有一个自由度。“流形”可以先理解成这样一个嵌在高维空间中的低维表面：局部看起来比较平直，整体可能弯曲。

欧氏距离是两点之间的直线长度；测地距离是沿表面允许路径的最短长度。Isomap 没有直接拿到真实表面，而是用采样点的邻域图近似表面，再用图上的最短路径近似测地距离。**图距离只是估计，不是算法发现了真实世界唯一正确的距离。** 如果特征距离本来没有业务含义，建图也不会自动修复这个问题。

## 2. 七个点，全部可以手算

按纸带顺序放置七个点，单位相邻间隔都是 1：

| 点 | 二维坐标 | 沿纸带的位置 |
|---|---|---|
| A | (0,0) | 0 |
| B | (0,1) | 1 |
| C | (0,2) | 2 |
| D | (1,2) | 3 |
| E | (2,2) | 4 |
| F | (2,1) | 5 |
| G | (2,0) | 6 |

如果只连接距离不超过 1.01 的点，图恰好是 A—B—C—D—E—F—G 的路径。A 到 G 的直线距离是 2，图最短路径长度却是 6。任意两点的图距离等于它们在表格中的位置之差的绝对值。这是一个人为设计、恰好能够在一维完全展开的案例；一般曲面和含噪采样没有这样的保证。

把半径改为 2.01，A 与 G 就会直接相连，最短路径降为 2。算法仍然正常输出坐标，但图已经允许跨越纸带两侧。这个现象叫“短路”：优化程序正确执行，也可能忠实地优化了一个错误的图。

## 3. 三个步骤如何把距离变成坐标

第一步，建立邻域图。每个样本是节点，边权通常是原始特征空间中的距离。常见选择是每个点的 k 个近邻，或固定半径内的邻居。k 近邻保证各点找到一定数量的邻居，却可能在稀疏区跨越很远；半径具有距离尺度的解释，却可能让稀疏区孤立。它们没有统一最优的默认值。

第二步，计算所有训练点之间的图最短路径，得到距离矩阵 D。多段短边相加，可以绕过表面的弯曲。scikit-learn 的源码在这一步使用无向最短路径，即使 k 近邻搜索本身可能产生不对称邻接关系。`dist_matrix_` 保存的是这一步的训练距离矩阵。

第三步，对距离做经典多维尺度分析式的展开。令 n 为样本数，I 为单位矩阵，1 为全一列向量：

\[
H=I-\frac{1}{n}\mathbf{1}\mathbf{1}^{\top},\qquad
B=-\frac{1}{2}H(D\odot D)H.
\]

这里 D⊙D 是每个距离分别平方，**不是矩阵乘法 D²**。H 的作用是去掉整体平移造成的影响。可以把 B 理解成“由距离反推出来、经过中心化的内积表”。取它最大的 d 个正特征值及对应特征向量，形成坐标：

\[
Y=V_d\operatorname{diag}(\sqrt{\lambda_1},\ldots,\sqrt{\lambda_d}).
\]

七点例子只有一个显著正特征值 28，因此一维即可还原全部路径距离。嵌入可能左右翻转；二维结果还可能旋转。这些变化不影响距离，不应把坐标正负解释成类别优劣。

真实图的最短路径距离未必能在目标维数的欧氏空间中完全实现，B 也可能含负特征值。丢弃方向会产生几何失真；严重不满足条件时库还可能报错。输出两列数字只表明请求了二维表示，不能证明数据本来只有两个因素。

## 4. 可运行的最小例子

```python
import numpy as np
from sklearn.manifold import Isomap

X = np.array([[0,0], [0,1], [0,2], [1,2], [2,2], [2,1], [2,0]], dtype=float)
model = Isomap(n_neighbors=None, radius=1.01,
               n_components=1, eigen_solver="dense")
Y = model.fit_transform(X)
print(model.dist_matrix_[0, -1])  # 6.0
print(Y.shape)                    # (7, 1)
new_Y = model.transform([[0, 0.5]])
print(new_Y.shape)                # (1, 1)
```

使用半径模式时要显式设置 `n_neighbors=None`，否则默认近邻数与半径同时存在，会被拒绝。`eigen_solver="dense"` 在这里用于很小的教学案例，不是大型数据的推荐配置。

完整[核验脚本](examples/isomap_checks.py)不只检查“有没有输出”：它把全部 49 个图距离与手算路径距离比较，用独立双中心化和 `numpy.linalg.eigh` 检查嵌入距离，核对大半径短路、互斥参数和新样本输出。运行：

```bash
python knowledge/unsupervised-learning/examples/isomap_checks.py
```

2026-10-04 实测：Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、scikit-learn 1.8.0。直线距离 2，路径距离 6，大半径路径距离 2；嵌入距离最大误差为 0，独立算得最大特征值约 28，新样本形状 (1,1)。全部断言通过，退出码 0，无警告。数值误差在其他平台可有微小变化，所以脚本按容差比较。没有进行大型性能测试、真实数据评估或邻域参数搜索。

## 5. 新样本映射与训练泄漏

Isomap 有 `transform`。它先把新点连接到已有训练点，再通过训练图估计到各训练点的路径距离，构造核并投影到训练时确定的坐标系。新样本没有重新参与训练点之间的图构建；这与把训练集和测试集合并后重新 `fit_transform` 的结果通常不同。

做下游分类或回归时，先划分数据；缩放、Isomap 和预测器只在训练部分拟合，验证数据依次调用 `transform` 和预测。交叉验证中使用 Pipeline，避免每折都看到了其他折的数据。为了展示全体样本而联合拟合可以有探索意义，但不能把同一结果当作严格的测试性能。

半径模式下，新样本可能没有任何训练邻居，本篇所核对的实现对这种情况没有通用兜底保证。实际使用前应检查邻居覆盖、拒绝或标记超出支持范围的样本，并通过验证集评估。能调用 `transform` 不等于能可靠处理分布外输入；它也不等于存在通用的 `inverse_transform` 来还原原始特征。

## 6. 参数调节应观察什么

| 观察项 | 可能的问题 | 可执行检查 |
|---|---|---|
| 原始邻域图的连通分量 | 邻域太小、采样缺口或真实分离群体 | 拟合前计算连通分量，保留警告 |
| 边的长度与跨区域连接 | 邻域过大、近邻越过折叠表面 | 检查最长边和领域上不应连接的对象 |
| 多组 k 或半径的距离变化 | 结论依赖特定参数 | 对比路径距离、局部邻居和下游验证分数 |
| 缩放前后的邻域 | 单位较大的特征主导距离 | 根据特征含义选择缩放，记录预处理 |
| 新样本邻居覆盖 | 训练图覆盖不足 | 统计无邻居或最近距离过大的比例 |

在此源码快照中，普通特征输入产生不连通图时，库会警告并尝试补边；稀疏预计算输入有特定报错分支。自动补边是实现上的补救，不能证明不同群体原本应该相连。如果数据包含多个独立流形，分组处理或改换方法可能更合理，不能只为了消除警告无限增加邻域。

## 7. 误差指标与内存边界

`reconstruction_error()` 衡量的是距离核与低维表示对应核的差异，采用 Frobenius 范数并除以样本数。它**不是原始特征的重建均方误差**。浮点抵消也可能影响极小误差。更换邻域参数会改变目标距离本身，因此误差变小未必意味着保留了更正确的几何。

局部指标如 trustworthiness 可以补充观察邻居有没有被错误拉近，但不能单独验证全局路径距离。若最终用于预测，应把业务验证表现、覆盖率和参数敏感性一起报告；若仅用于绘图，应避免把图中空隙直接解释成真实群体分隔。

Isomap 虽然从稀疏邻域图开始，却会保存 n×n 的训练距离矩阵。仅一个 float64 距离矩阵，n=10,000 时约 800 MB（约 763 MiB），n=50,000 时约 20 GB；平方矩阵、中心化核及求解器还会增加内存。近邻搜索、全点对最短路径和特征分解也需要时间。`n_jobs=-1` 不能消除这些成本。不要因为输入图稀疏就认定整个算法可以轻松处理数百万样本。

## 8. 与已经学过的方法连接

| 方法 | 主要想保留什么 | 本篇需要记住的边界 |
|---|---|---|
| PCA | 线性投影中的方差 | 对折叠曲面不一定能展开 |
| Isomap | 邻域图估计的全局测地距离 | 对短路、断连和采样覆盖敏感 |
| t-SNE | 由概率相似度描述的邻域关系 | 图中全局距离和面积不能直接照原空间理解 |
| 谱聚类 | 图上较紧密的成员分组 | 输出分组与输出几何坐标是不同任务 |

自测：为什么七点例子半径 2.01 会得到“更短”的路径？因为新增 A—G 边权为 2，最短路径直接使用它。为什么把七点输出翻转不算错误？因为任意两点之间的距离没有改变。为什么训练图全部连通还不够？因为一个错误的跨表面连接就能连通图，同时破坏测地距离。
