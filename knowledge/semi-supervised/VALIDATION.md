# 验证记录

执行日期：2026-10-04。Python 3.12.14、NumPy 2.3.5、scikit-learn 1.8.0。脚本实际运行，退出码0，无stderr。它调用真实SelfTrainingClassifier，不是自行模拟该API。

## 机制检查

使用均匀概率DummyClassifier，固定每类概率为0.5；这些检查只关注筛选和状态，不代表DummyClassifier有预测能力。

| 案例 | 已通过断言 |
| --- | --- |
| threshold=0.5 | 恰好相等的样本不接收；no_change；未标注仍为-1 |
| threshold=0.49 | 所有未知样本在第1轮接收；all_labeled |
| k_best=1、max_iter=1 | 只接收1个；其余3个保持未知；max_iter |
| 原始2个人工标签 | 标签不被覆盖，labeled_iter为0 |

## 固定数据上的独立测试

随机配置固定在脚本中；600条合成样本先切成400条训练池、200条测试。训练池每类选20条，合计40条作为模拟真实标注，其余360条的标签隐藏。底层为StandardScaler加LogisticRegression；阈值固定0.9，最多10轮，测试集不用于调参。

| 观测 | 实际结果 |
| --- | --- |
| 接收伪标签 | 237条 |
| 仍未接收 | 123条 |
| 自训练轮数 | 9 |
| 停止原因 | no_change |
| 纯监督基线测试准确率 | 0.775 |
| 自训练测试准确率 | 0.785 |
| 已接收伪标签的事后审计准确率 | 0.8987341772151899 |

隐藏真值仅用于模拟标注抽样和训练结束后的审计；未传入拟合、未用于选择阈值。样本抽样在模拟中确保每类20条，实际项目不应假定未知池真值可用。两种模型采用同一人工标签预算和同一测试集。

差异为1个百分点，单一随机种子、200条测试不构成稳健收益证据。未测多随机种子置信区间、真实工单分布、标签噪声强度扫描、类别失衡或线上收益。没有断言自训练优于基线，以免把教学验证变成结论导向的数据选择。

重跑：[self_training_checks.py](examples/self_training_checks.py)。来源版本说明见[来源清单](SOURCES.md)。
