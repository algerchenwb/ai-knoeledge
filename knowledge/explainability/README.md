# 模型可解释性：重要性、响应曲线与单次预测贡献

先明确想回答的问题，再选择方法。建议已理解 [评估与数据泄漏](../ml-evaluation/README.md)、[经典机器学习](../classical-ml/README.md) 后阅读。

| 业务问题 | 方法 | 实际解释的对象 | 主要边界 |
| --- | --- | --- | --- |
| 模型预测表现依赖哪些字段？ | [置换重要性](01-permutation-importance.md) | 固定模型在指定数据与指标上的依赖 | 相关字段、差模型、指标方向 |
| 输入变化时，模型响应怎样变化？ | [PDP 与 ICE](02-pdp-and-ice.md) | 平均与个体的模型响应 | 群体抵消、不自然组合、背景构成 |
| 这个样本相对参考值为什么得到该预测？ | [Shapley 与 SHAP](03-shapley-and-shap.md) | 某个输出差值的特征分配 | 背景与缺失规则、输出单位、近似 |
| 现实中采取行动能改善多少？ | 需要另外设计因果分析或实验 | 干预对现实目标的效果 | 上述解释工具不能自动完成因果识别 |

本专题为独立中文讲解，来源主要为 scikit-learn 与 SHAP 的官方 GitHub 仓库，已记录固定提交和许可。文章包含通俗机制、完整手算、门店业务示例、常见误区、练习与答案；未复制上游图片或参考代码。详细来源见 [SOURCES.md](SOURCES.md)。

## 可运行的示例

标准库数学检查，不需要安装机器学习库：

```bash
python knowledge/explainability/examples/explanation_math.py
```

真实 scikit-learn 集成检查，需要 NumPy 与 scikit-learn：

```bash
python knowledge/explainability/examples/sklearn_inspection_checks.py
```

第二个脚本会打印实际依赖版本、置换均值/标准差及 PDP 数值；本次没有下载数据集，全部使用可复现人工数据。脚本说明了哪些模型经过拟合，哪些是为隔离解释机制而定义的已知函数。

| 检查 | 已运行结果 |
| --- | --- |
| 指定一次置换的误差 | 两个字段 MSE 增加为 4 和 1 |

## 一份解释报告应该保留什么

记录模型版本、评估样本范围、字段语义、指标/输出单位、解释方法、参考背景与缺失规则、随机种子、重复次数和验证限制。若是分类输出，写清类别与概率校准状态；若是业务动作建议，写清还缺哪些证据。

例如可以写“在固定门店评估集上，打乱客流使该模型的负 MSE 分数平均下降某个数值”；不能仅据此写“增加客流必然带来等量利润”。以上报告要求为独立工程建议。
